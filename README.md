# 🔍 insta-followers

**¿Quién no te sigue de vuelta?** Compara tus seguidores y seguidos de Instagram y descubre las dos diferencias:

- A quién **sigues** y no te sigue de vuelta
- Quién **te sigue** y no sigues de vuelta

## Cómo se usa

1. En Instagram: Configuración → Centro de cuentas → Tu información y permisos → **Descargar tu información**.
2. Pide «Seguidores y seguidos» en formato **JSON** y descarga el `.zip`.
3. Súbelo en la app: **https://tec-girl.github.io/insta-followers.github.io/**

También acepta los archivos `followers_1.json` y `following.json` sueltos, o pegar las listas a mano.

## Privacidad

100% local: todo se calcula en el navegador de la persona. Nada se sube a ningún servidor.
La API oficial de Instagram no entrega estas listas con login; los sitios que piden usuario y
contraseña de Instagram son inseguros. La exportación oficial es la vía segura.
